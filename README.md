# 背单词 · 翻转单词卡片（Web 线 W-1）

浏览器端单页应用：**双击 `index.html` 即可使用**，单文件、离线可用、无需框架 / 构建工具 / CDN。

> 当前状态（2026-11-07）：W-1 已由程序员浏览器验收通过，交付于远程仓库 `Rorenchai/wordsREApp` 的 `web` 分支（提交 `ba6d731`）。
> 对应任务卡：`07_任务卡_Web线W-1_翻转单词卡片.md`（项目根目录）。

## 功能

| 功能 | 说明 |
|---|---|
| 单词卡片 | 正面：大号拼写 + 级别徽章（PETS / CET4 / CET6，三色区分）；背面：拼写 + 中文释义 |
| 3D 翻转 | 点击卡片正反翻转（`preserve-3d` + `rotateY`）；换词时自动回到正面 |
| 随机抽词 | 「下一个」随机取词，且**不连续出现同一个词** |
| 掌握标记 | 「已掌握 / 取消掌握」可反复切换 |
| 进度统计 | 已学 X / 20　已掌握 Y　掌握率 Z%（掌握率 = 已掌握 ÷ 20 × 100%，取整） |
| 持久化 | localStorage 保存已学与掌握集合，刷新页面不丢 |
| 重置 | 清空两个存储键与内存状态，回到初始词（词库第一条 `beautiful`） |

## 页面元素与数据口径

| 项 | 取值 |
|---|---|
| 三个按钮 | `下一个` / `已掌握`（掌握后变 `取消掌握`）/ `重置` |
| 存储键 | `wordsre_mastered`、`wordsre_viewed`（存的是**词下标集合**，不含 level） |
| 词库 | 内嵌 20 词，与 Android 端 `Study/app/src/main/assets/words.json` **逐条一致**；分布 PETS×7 / CET4×7 / CET6×6 |
| 状态口径 | 已学 = 浏览过的不同单词数；已掌握 = 掌握集合大小 |
| 容错 | localStorage 不可用或内容非合法 JSON 时按空状态处理，页面照常可用 |

## 技术栈

- 原生 HTML5 + CSS3 3D 变换 + 原生 JavaScript（ES6），**无框架、无构建、无 CDN**
- 深色/浅色无关的独立配色，含移动端窄屏适配
- 不依赖后端、不依赖 Android 工程；与 Android 端仅「词库内容一致」，代码互不依赖

## 快速开始

1. 本仓库位于 `Web/` 目录，独立 git 仓库，本地分支 `main` 跟踪远程 `web` 分支
2. 用 Chrome / Edge 双击 `index.html`（或拖进浏览器窗口）
3. 验收断网能力：F12 → Network → Offline，刷新后功能仍可用
4. 每次验收前先点一次「重置」，保证从干净状态开始
